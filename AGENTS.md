# MiniBoard — Lab rules
- This is a public, greenfield demonstration. No private user data, ChatGPT tokens, authenticated profile material, proprietary RDR2/WCC/LoopStar source, or downloaded secrets may enter Git.
- Each development cycle uses one stable `main` lineage and a scoped feature branch or commit; preserve the previous accepted code, tests and release notes. Do not rewrite history or force-push.
- Read PROJECT_TRUTH → CONTEXT → HANDOFF → ROADMAP → QUEUE → ADR before edits; update only what changes and record corrections in LESSONS_LEARNED.
- Real cycle acceptance: pinned start SHA → completed ChatGPT turn receipt → functional diff → tests with results → Git commit and new SHA → final LoopStar DONE checkpoint.
- The seed is not cycle 1. Do not invent evidence or treat STEP numbers as independent cycles.
- No paid APIs, hosting, deployment, private data, or new permission without owner consent.
- Run `npm test` after each development change. Keep responsive RTL/LTR, keyboard, focus, empty, error and light/dark states usable.

# LoopStar MiniBoard — Public Development Lab

A real **public** local-first product seed created to verify **two independent, meaningful LoopStar development cycles**. This repository is a new product, not a copy of private LoopStar/WCC/RDR2 source.

## Run

```bash
npm test
npm start
```

Open http://127.0.0.1:4177. Requires Node.js 22.16+; no `npm install` or paid API.

## Scope

- Seed (current): responsive RTL empty-state and a safe local HTTP server. **0/2 development cycles accepted**.
- Cycle 1: task CRUD and local persistence plus functional/browser QA.
- Cycle 2: search, filters, priorities, change history, interruption/resume regression.

Use one original LoopStar T4/Edge controller and a **new approved chat URL** assigned to this lab. Only mark a cycle complete after a positively attributed ChatGPT turn, actual code diff/tests, a new Git commit and matching original LoopStar receipt. No secrets/private data may be published.
